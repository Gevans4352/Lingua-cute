# LinguaCute!!!!

LinguaCute is a language learning web application designed to make language practice engaging through translation tools, structured learning modules, and interactive games. The platform combines educational features with a modern interface to provide an enjoyable and accessible language learning experience.

The application was initially designed with a soft pink aesthetic and later redesigned with a vibrant brown and orange theme to create a more energetic and visually engaging interface.

---

## Overview

LinguaCute provides three primary learning experiences within a single platform:

- Translation tools for quick language conversion
- Structured learning sections for vocabulary and language exposure
- Interactive games that reinforce language skills

The application also includes a complete authentication system and a user dashboard where learners can track progress and access all platform features.

---

## Features

### Translation Tool
The Quick Convert feature allows users to translate sample phrases between multiple languages. It serves as a demonstration of the translation functionality within the application.

Capabilities include:
- Multiple language options
- Instant phrase translation
- Interactive interface for quick testing

---

### Learning Modules
The learning section introduces vocabulary and language concepts through interactive cards and structured content.

Key elements include:
- Animated feature cards
- Organized learning sections
- Interactive UI components

---

### Language Games
LinguaCute includes several games designed to reinforce vocabulary, sentence structure, and language recognition.

Current games include:

- **Word Match** – Match words with their corresponding translations
- **Speed Quiz** – Timed quiz questions to test vocabulary knowledge
- **Sentence Builder** – Arrange words to construct correct sentences
- **Listening Challenge** – Identify spoken words or phrases
- **Memory Cards** – Flip cards to match language pairs
- **Battle Royale** – Competitive language challenge mode

---

## Authentication System

The platform includes a complete authentication flow with the following pages:

- Login page
- Registration page
- Forgot password page
- Custom 404 error page

These pages maintain consistent styling with the rest of the application.

---

## User Dashboard

After authentication, users are redirected to a dashboard that serves as the main interface for the platform. Navigation is provided through a sidebar layout.

Dashboard sections include:

- **Home** – Welcome screen with user activity and overview
- **Learning Progress** – Displays course progress and achievements
- **My Translations** – Stores previously translated phrases
- **Games and Challenges** – Access to all language games
- **Leaderboard** – Ranking system for competitive game modes
- **Profile** – User profile management
- **Settings** – Application preferences and account configuration
